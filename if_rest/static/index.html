Features

  • Face Management: Add, update, delete, and search faces
  • Face Search: Find similar faces using FAISS-based similarity search
  • API Connectivity: Connect to local or remote API servers
  • GPU Support: Optional GPU acceleration for similarity search
  • Data Persistence: Docker volumes for persistent storage
  • Bulk Registration: Scripts to register multiple faces at once

About

This system provides face management and search capabilities using:

  • SQLite for face data storage
  • FAISS for fast similarity search
  • InsightFace for face detection and recognition
  • FastAPI for the REST API
